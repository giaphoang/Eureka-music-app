# Skills Demonstrated

- Desktop event-driven architecture with Qt signals/slots.
- Non-blocking background execution with `QThreadPool` and `QRunnable`.
- Local audio playback and seek/state synchronization.
- REST API design with JSON, multipart uploads, and streamed downloads.
- PostgreSQL and SQLite persistence with transactional writes.
- Crash-safe file handling using temporary files, `fsync`, and atomic rename.
- Docker Compose service dependency and health checks.
- Dataset ingestion from FMA multi-level CSV metadata.
- Model/view UI design suitable for thousands of tracks.
- Design documentation with context, container, ERD, sequence, and flow diagrams.
